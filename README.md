# Лабораторная работа 3 Вариант 1 Фоторедактор

Консольный просмотрщик и редактор фотографий на C#/.NET 9 для Windows. Поддерживает обрезку, поворот, коллажи, надписи, изменение отдельных пикселей, фильтры и сохранение всей рабочей сессии. Графический интерфейс не нужен по условию задания.

## Запуск

Откройте `Lab3PhotoEditor.sln` в Visual Studio с поддержкой .NET 9 и назначьте проект `Lab3PhotoEditor` запускаемым. Для запуска в терминале из папки решения:

```powershell
dotnet run --project Lab3PhotoEditor/Lab3PhotoEditor.csproj
```

Требуются Windows и .NET 9 Desktop Runtime (либо SDK с компонентом Windows Desktop). Библиотека System.Drawing подключена через Windows Desktop Framework. Параметр UseWindowsForms в csproj нужен для этой библиотеки; приложение не создаёт графических окон.

## Как пользоваться

Выберите действие по номеру, введите параметры и нажмите Enter. Путь к файлу можно вставлять в кавычках.

| Пункт | Действие |
| --- | --- |
| 1 | Добавить фотографию из PNG, JPEG, BMP, GIF или TIFF |
| 2 | Вывести список и выбрать фотографию |
| 3 | Показать название, размеры и объём данных выбранной фотографии |
| 4 | Обрезать по координатам X/Y, ширине и высоте |
| 5 | Повернуть на угол, кратный 90°, по часовой стрелке; отрицательный — против |
| 6 | Добавить надпись: текст, координаты, размер шрифта в пикселях и RGB |
| 7 | Посмотреть цвет пикселя и заменить его новым RGB |
| 8 | Применить яркость, чёрно-белый фильтр, негатив, сепию или баланс RGB |
| 9 | Создать коллаж из выбранных номеров фото, указав число столбцов и размер ячейки |
| 10 | Экспортировать выбранный результат в PNG, JPEG или BMP |
| 11 | Сохранить весь проект |
| 12 | Загрузить весь проект из сохранения |
| 13 | Удалить выбранное фото из проекта после подтверждения |
| 14 | Показать справку |
| 0 | Сохранить проект и завершить программу |

Координаты начинаются с нуля в левом верхнем углу. X растёт вправо, Y вниз. Обрезка должна полностью попадать внутрь изображения. Надпись может частично выйти за край — эта часть не будет видна. Отрицательная яркость затемняет, положительная осветляет; диапазон от -100 до 100 означает добавление доли полного диапазона канала. Баланс RGB добавляет значения от -255 до 255 к каждому каналу отдельно, результат ограничивается диапазоном 0..255.

В коллаже фотографии располагаются по строкам в указанном порядке. Допустимы повторные номера. Пропорции фото сохраняются, свободное пространство заполняется белым. Коллаж добавляется как отдельная фотография, исходные документы остаются в проекте.

В терминале выводятся только сведения о фотографии. Все операции обрабатывают настоящее изображение в полном разрешении. Для просмотра результата экспортируйте его пунктом 10 и откройте полученный файл обычным просмотрщиком фотографий.

## Сохранение и ограничения

Проект хранится в `saves/photo-project.json` рядом с исполняемым файлом. При запуске Debug путь обычно такой: `Lab3PhotoEditor/bin/Debug/net9.0-windows/saves/photo-project.json`. Программа выводит полный путь после сохранения. Сборки Debug и Release используют разные каталоги сохранения.

Сериализуются список фотографий, названия, выбранный номер и данные каждого обработанного изображения в PNG (в JSON это Base64). Для продолжения работы исходные файлы больше не нужны. Пункт 0 сохраняет перед выходом; после перезапуска выберите 12 и подтвердите загрузку. Принудительное закрытие окна не гарантирует сохранения. Один слот проекта перезаписывается при сохранении. При загрузке несохранённые изменения заменяются после подтверждения.

Сохранение сначала записывается во временный файл, затем заменяет основной. Версия, выбранный индекс и все изображения проверяются при сохранении и загрузке. Пустой проект тоже можно сохранить. Ошибка операции не должна заменять текущее изображение частичным результатом.

Исходный файл не меняется при импорте и обработке. Экспорт по существующему пути выполняется после подтверждения. PNG сохраняет прозрачность, JPEG использует белый фон. GIF и TIFF импортируются как статическое изображение: анимация и несколько страниц не поддерживаются. Метаданные EXIF не сохраняются, автоматическая ориентация по EXIF и отмена операций не реализованы. Размер изображения или итогового коллажа ограничен 24 млн пикселей; фотографии хранятся в памяти и внутри JSON.

## Проектирование и интерфейсы

| Файл | Ответственность |
| --- | --- |
| `PhotoProject.cs` | Модель проекта, документы фото, перечисление фильтров, интерфейсы IImageProcessor и IProjectStorage |
| `ImageProcessor.cs` | Декодирование, обрезка, поворот, надпись, пиксели, фильтры, коллаж, экспорт |
| `JsonProjectStorage.cs` | Проверка, сериализация и десериализация проекта |
| `PhotoInfoPrinter.cs` | Название, размеры и объём данных фото |
| `Program.cs` | Меню, ввод, выбор фото, вызов обработки и обработка ошибок |
| `PhotoEditorTests.cs` | Модульные тесты изображений и проекта |
| `MSTestSettings.cs` | Параллельное выполнение тестов |

Программа обращается к обработчику через `IImageProcessor`, к сохранению через `IProjectStorage`. Обработчик получает байты изображения и возвращает новый PNG; исходный массив не изменяется. Новый результат назначается документу только после успешной операции. Все Bitmap, Graphics, Font, кисти и потоки освобождаются через using.

Предлагаемое распределение работы бригады: один участник отвечает за модель и интерфейсы, второй за ImageProcessor, третий за сохранение, четвёртый за консольное меню и тесты. Фактические имена участников и выполненную ими работу студенты указывают самостоятельно; авторство команды не выдумывается.

## Проверка

```powershell
dotnet test Lab3PhotoEditor.sln -m:1
```

MSTest проверяет реальные пиксели и размеры после обрезки, поворота, фильтров и коллажей, наличие пикселей надписи, неизменность оригинала, недопустимые параметры, экспорт PNG/JPEG/BMP, пустые и повреждённые проекты и восстановление правок без исходных файлов. Файловые тесты работают в собственных временных каталогах и не используют пользовательский слот.

Ручной сценарий: добавьте фото → измените пиксель → поверните → сохраните проект → выйдите → запустите снова → загрузите → экспортируйте PNG. Сравните выбранный документ, размеры и изменённый пиксель. Для коллажа добавьте два фото разных пропорций и проверьте порядок и белые поля.

Локальный Git-репозиторий содержит исходники, тесты и документацию. Сборочные файлы и сохранения исключены через .gitignore. Удалённый репозиторий и публикация не настраиваются автоматически.
